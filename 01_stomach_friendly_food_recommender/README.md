# Stomach Friendly Food Recommender

위에 부담이 적은 음식을 추천하는 미니 프로젝트입니다.  
음식 데이터를 기반으로 맵기, 기름짐, 밀가루 포함 여부, 카페인 포함 여부를 확인하고 조건에 맞는 음식을 필터링합니다.

## 프로젝트 목적

위염 증상이 있거나 자극적인 음식을 피해야 하는 상황에서 비교적 부담이 적은 음식을 고를 수 있도록 간단한 추천 프로그램을 만들었습니다.

## 사용 데이터

`food_sample.csv` 파일을 사용했습니다.

| 컬럼명 | 설명 |
|---|---|
| food_name | 음식명 |
| category | 음식 분류 |
| spicy | 매운 음식 여부 |
| greasy | 기름진 음식 여부 |
| contains_flour | 밀가루 포함 여부 |
| contains_caffeine | 카페인 포함 여부 |
| description | 음식 설명 |

## 주요 기능

- 음식 CSV 데이터 불러오기
- 매운 음식 제외
- 기름진 음식 제외
- 밀가루 포함 음식 제외
- 카페인 포함 음료 제외
- 조건에 맞는 음식 추천 결과 저장

## 사용 기술

- Python
- pandas
- CSV 데이터 처리
- 조건 기반 필터링
