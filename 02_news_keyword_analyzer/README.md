# News Keyword Analyzer

뉴스 제목 데이터를 기반으로 주요 경제 키워드의 등장 빈도를 분석하는 미니 프로젝트입니다.  
경제 뉴스 분석 서비스인 DATA 프로젝트를 진행하기 전, 뉴스 데이터 처리와 키워드 빈도 분석 흐름을 연습하기 위해 만들었습니다.

## 프로젝트 목적

뉴스 제목에서 자주 등장하는 키워드를 추출하고, 키워드별 빈도를 계산하여 경제 뉴스의 주요 이슈 흐름을 간단히 확인합니다.

## 사용 데이터

`news_sample.csv` 파일을 사용했습니다.

| 컬럼명 | 설명 |
|---|---|
| date | 뉴스 날짜 |
| title | 뉴스 제목 |

## 주요 기능

- CSV 뉴스 데이터 불러오기
- 분석할 키워드 목록 정의
- 뉴스 제목 내 키워드 포함 여부 확인
- 키워드별 등장 빈도 계산
- 분석 결과 CSV 저장
- 키워드 빈도 그래프 생성

## 사용 기술

- Python
- pandas
- collections.Counter
- matplotlib
