# Job Posting Keyword Analyzer

채용공고 데이터를 기반으로 주요 기술스택 키워드의 등장 빈도를 분석하는 미니 프로젝트입니다.  
공고 제목과 직무 설명에서 개발·데이터 직무에서 자주 요구되는 기술 키워드를 추출하고 시각화합니다.

## 프로젝트 목적

취업 준비 과정에서 채용공고에 자주 등장하는 기술스택을 확인하고, 현재 학습한 기술과 시장에서 요구하는 기술의 연결성을 파악하는 것이 목적입니다.

## 사용 데이터

`job_postings_sample.csv` 파일을 사용했습니다.

| 컬럼명 | 설명 |
|---|---|
| job_id | 채용공고 번호 |
| job_title | 채용공고 제목 |
| description | 채용공고 설명 |

## 주요 기능

- 채용공고 CSV 데이터 불러오기
- 분석할 기술스택 키워드 정의
- 공고 제목과 설명에서 키워드 포함 여부 확인
- 기술스택별 등장 빈도 계산
- 분석 결과 CSV 저장
- 기술스택 빈도 그래프 생성

## 사용 기술

- Python
- pandas
- collections.Counter
- matplotlib
- CSV 데이터 처리
